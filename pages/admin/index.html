使用指引

  1. 到「行为设置」点击右上角「＋ 添加群聊」，添加即默认启用。
  2. 选择模式：完全封锁 / 被@回复。
  3. 配置时间段：每天、自定义星期或指定日期，支持跨午夜。
  4. 总览可随时启停；封锁时段内仅放行 @、管理员与 / 指令（被@回复模式）。
